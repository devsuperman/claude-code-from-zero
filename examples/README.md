# Running project

Throughout the course, you will evolve a small **URL shortener** using Claude Code. The idea is to practice each module on the same code and watch the project grow.

> Under construction. The initial version of the project will be added here. Until then, do the exercises on a project of your own.

## Plan

| Module | What we do in the project |
|--------|---------------------------|
| 01 | Compare the before × after flow: add URL validation |
| 05 | Explore the codebase and observe permissions and context |
| 06 | Add URL validation with a good prompt |
| 07 | "Existing" path: map the codebase, generate the `CLAUDE.md` and do the first task |
| 08 | "New" path: build the shortener from scratch, in slices with tests and commits |
| 09 | Plan and implement link expiration |
| 13 | Add tests and use them as the success criterion |
| 14 | Open a PR with Claude's help |
