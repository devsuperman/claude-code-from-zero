# Projeto-fio-condutor

Ao longo do curso, você evoluirá um **encurtador de URLs** pequeno usando o Claude Code. A ideia é praticar cada módulo sobre o mesmo código, vendo o projeto crescer.

> Em construção. A versão inicial do projeto será adicionada aqui. Até lá, faça os exercícios em um projeto seu.
