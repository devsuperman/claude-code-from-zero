# 00 · Antes de começar

_Última revisão: 2026-10_

**Objetivo:** saber o que é o Claude Code e o que você precisa para acompanhar o curso.

## O que é

Um **agente de código**. Você descreve um objetivo; ele lê o projeto, edita arquivos, roda comandos e itera até concluir ou pedir ajuda. Roda no terminal, em IDEs, no app desktop e na web.

## Como difere do que você já usa

| | Chat | Autocomplete | Claude Code |
|---|---|---|---|
| Vê seu código | Só o que você cola | Arquivo aberto | Projeto inteiro, sob demanda |
| Executa comandos | Não | Não | Sim, com sua permissão |
| Edita vários arquivos | Não | Limitado | Sim |
| Itera sozinho (testa, corrige) | Não | Não | Sim |
| Quem dirige | Você, copiando e colando | Você, linha a linha | Você define o objetivo |

## Pré-requisitos

- Terminal e git no dia a dia
- Um projeto de código (pode ser pequeno)
- Conta com acesso ao Claude Code (Pro/Max ou API). Veja planos e limites na documentação oficial.

## Custo

O uso consome tokens; sessões longas consomem mais. Sessões curtas, tarefas focadas e `/clear` entre assuntos reduzem custo e melhoram o resultado. `/cost` mostra o consumo.

## Quando não usar

- Decisão que você ainda não entende: peça explicação ou plano, não implementação.
- Mudança que você faz em 10 segundos.
- Diretório com segredos expostos.
