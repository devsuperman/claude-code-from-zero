# 00 · Before you start

_Last reviewed: 2026-10_

**Goal:** know what Claude Code is and what you need to follow the course.

## What it is

A **coding agent**. You describe a goal; it reads the project, edits files, runs commands and iterates until it finishes or asks for help. It runs in the terminal, in IDEs, in the desktop app and on the web.

## How it differs from what you already use

| | Chat | Autocomplete | Claude Code |
|---|---|---|---|
| Sees your code | Only what you paste | Open file | Whole project, on demand |
| Runs commands | No | No | Yes, with your permission |
| Edits several files | No | Limited | Yes |
| Iterates on its own (tests, fixes) | No | No | Yes |
| Who drives | You, copying and pasting | You, line by line | You set the goal |

## Prerequisites

- Comfortable with the terminal and git day to day
- A code project (it can be small)
- An account with access to Claude Code (Pro/Max or API). See plans and limits in the official documentation.

## Cost

Usage consumes tokens; long sessions consume more. Short sessions, focused tasks and `/clear` between topics reduce cost and improve results. `/cost` shows consumption.

## When not to use it

- A decision you don't understand yet: ask for an explanation or a plan, not an implementation.
- A change you can make in 10 seconds.
- A directory with exposed secrets.

## Checklist

- [ ] I know the difference between chat, autocomplete and an agent
- [ ] I have a project to practice on
